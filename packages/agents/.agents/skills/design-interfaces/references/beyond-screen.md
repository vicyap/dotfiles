# Beyond And Behind The Screen

Screen interactions may be one surface of a larger system. Model what the system
knows, senses, predicts, and controls; make those boundaries legible to the user.
Do not imply certainty, agency, or connectivity that the product does not have.

## System Types

### Connected Devices
Represent device identity, connection, synchronization, ownership, and last-known
state explicitly. Design pairing, offline operation, conflict resolution,
handoff, permission, and safe removal before adding remote convenience.

### Anticipatory Systems
Offer likely next actions or prepare work from context when confidence and benefit
are high. Show why a suggestion appeared, keep it distinguishable from completed
work, allow correction, and never automate consequential action without suitable
control.

### Assistive Systems
Reduce effort by augmenting rather than obscuring user agency. Communicate what
the system can do, request confirmation proportional to risk, expose status and
failure, and provide a manual route.

### Natural User Interfaces
Use touch, gesture, voice, movement, or physical manipulation when it matches the
environment and task. Provide discoverability, feedback, privacy, tolerance for
variation, and an accessible fallback; avoid calling an unfamiliar gesture
natural merely because it uses the body.

## Review Checklist

- What data and context does the system use, and can users understand and control it?
- What happens when sensing, prediction, connectivity, or synchronization is wrong?
- Is suggested work clearly different from completed work?
- Can users inspect, override, undo, disconnect, and recover safely?
- Is there an equivalent route when a physical, vocal, sensory, or network
  capability is unavailable?
